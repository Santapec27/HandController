**HandController** es un proyecto de visión por computadora que permite interactuar con el sistema operativo mediante el seguimiento y reconocimiento de gestos de la mano en tiempo real a través de una cámara web. Diseñado para ofrecer una experiencia de control sin contacto, intuitiva y accesible.
**HandController** is a computer vision project that allows users to interact with their operating system through real-time hand tracking and gesture recognition via a webcam. Designed to provide an intuitive, accessible, and touchless control experience.
